## 소개

**JUSIAI GAMES**는 기획, 아트, 개발까지 혼자 하는 1인 게임 개발사입니다.

브랜드는 작은 어항 하나에서 시작했습니다. 라임빛 수초 사이를 헤엄치는 노란 구피가 마스코트입니다. 구피는 작은 어항 안에서도 쉬지 않고 헤엄칩니다. 저희도 작게 만들고, 자주 보여드리고, 꾸준히 나아가려 합니다.

## 일하는 방식

- **작게 만듭니다.** 혼자서도 끝까지 만들 수 있는 크기의 게임을 만듭니다.
- **자주 보여드립니다.** 완성 전의 과정도 데브로그에 공개합니다.
- **꾸준히 나아갑니다.** 한 번에 크게 뛰기보다 매일 조금씩 헤엄칩니다.
