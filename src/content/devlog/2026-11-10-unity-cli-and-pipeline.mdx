1인 게임 개발을 하겠다고 마음먹은 그날 밤, 나는 바로 유데미에서 유니티(Unity) 강의를 결제했다. 이유는 단순했다. 내가 들어 본 게임 엔진이 "유니티"뿐이었기 때문이다. 그때 나는 두 가지만 생각했고, 그 둘이 함께 성립하는지는 생각하지 못했다.

- 하나, 게임을 개발할 것이니 내가 들어 봤고 가장 유명해 보이는 유니티를 쓰자.
- 둘, AI 에이전트(클로드, 코덱스)로 리소스 생성부터 코딩까지 전부 해 보자.

정말 바보 같지만, 1인 개발이 성립하려면 반드시 검증해야 하는 가장 위험한 가정(riskiest assumption)인 "AI 코딩 에이전트를 쓸 수 있는가"를 확인하지 않은 것이다.

## 유니티와 AI 에이전트의 궁합

유데미에서 유니티 강의를 12시간쯤 듣다가 한 가지가 걸렸다. 유니티는 코드만으로 게임을 만들 수 없고, 에디터에서 오브젝트를 연결하고 애니메이션을 처리하고 파라미터를 조절해야 한다. 이런 작업까지 AI에게 맡기면 협업이 어렵지 않을까? 유니티에도 강력한 에디터(Editor) API가 있었지만, 외부 에이전트가 이를 활용하도록 연결하는 작업은 상대적으로 복잡했다. AI 에이전트가 유니티 에디터를 직접 제어하기 어려우니 궁합이 좋을 리 없었다.

요즘 구독하고 있는 1인(혹은 소규모) 게임 개발 랩들이 고돗(Godot)을 많이 쓰는 것도 그래서인지 모른다. 고돗은 처음부터 AI를 위해 만들어진 엔진은 아니지만, 텍스트 기반 씬과 명령줄 중심의 개발 환경 덕분에 AI 코딩 에이전트와 자연스럽게 잘 맞는다고 한다.

- 텍스트 기반 씬 파일: AI가 .tscn 파일을 직접 읽고 고치기 쉽다.
- 강력한 CLI 지원: 오래전부터 터미널에서 프로젝트 실행, 테스트, 에셋 임포트 등을 할 수 있었다.
- 간단한 프로젝트 구조: 씬, 스크립트, 리소스가 비교적 직관적으로 구성되어 AI가 프로젝트 전체를 파악하기 쉽다.
- 자동화하기 쉬운 개발 흐름: AI가 파일 수정 → CLI 실행 → 오류 확인 → 재수정을 반복하기 편하다.

## Unity CLI와 Pipeline 패키지

그런데 찾아보니 유니티에도 길이 있었다. Unity는 2026년 5월 11일 Unity AI 오픈 베타의 MCP 서버를 Claude Code, Cursor 등에 연결하는 방법을 공식 블로그에 소개한 데 이어, 7월 20일에는 공식 CLI와 실험적인 파이프라인(Pipeline) 패키지를 함께 발표했다. 이 "Unity CLI"를 쓰면 AI 에이전트도 에디터를 직접 다룰 수 있다. 이번 글의 주제가 바로 유니티 CLI와 파이프라인 패키지다.

구조는 단순하다. AI 에이전트가 터미널에서 명령을 내리면 Unity CLI가 그 명령을 전달하고, 프로젝트에 설치한 Pipeline이 받아서 실행 중인 Editor에서 처리한다. CLI가 명령을 전달하는 입구라면, Pipeline은 그 명령을 Editor 안에서 실행하도록 이어 주는 통로다.

<PostImage src={`${IMAGE_URL_2026}/unity-cli-and-pipeline-01.avif`} alt="Unity CLI가 Pipeline 패키지를 거쳐 실행 중인 Unity Editor에 명령을 전달하는 아키텍처" />

Unity CLI는 터미널의 진입점으로, Unity 전체를 명령줄에서 관리하는 도구다.

- Unity Editor 설치 및 버전 관리
- 프로젝트 생성과 실행
- 로그인 및 인증
- 빌드와 테스트 자동화
- Pipeline을 통한 실행 중인 Editor 제어
- C# 코드 실행(`unity command eval`)

Unity Pipeline은 Unity 프로젝트에 설치하는 패키지로, 실행 중인 Editor 안에서 작업을 수행한다.

- 로컬 HTTP API로 명령 수신
- GameObject와 씬 조작
- 에셋 및 컴포넌트 관리
- Editor 상태 조회
- 테스트와 개발 작업 자동화
- 사용자 정의 명령 실행

지금 개발 중인 게임의 프로토타입도 유니티로 만들고 있다. 유니티 CLI를 쓰니 지금까지 AI 에이전트와 협업하면서 막힌 적 없이 수월했다.

## Unity CLI 설치와 로그인

이제 설치 방법을 살펴보자. 이 글은 윈도우를 기준으로 설명한다. 먼저 PowerShell에서 winget으로 Unity CLI를 설치한다.

```
PS C:\Users\Developer\Desktop\workspace\projects\the-mage-next-run> winget install --id Unity.CLI -e
```

다음 명령어로 설치가 끝났는지 확인할 수 있다.

```
PS C:\Users\Developer\Desktop\workspace\projects\the-mage-next-run> unity --version
1.0.0-beta.13
```

`help` 명령어로 Unity CLI가 제공하는 명령어를 볼 수 있다.

```
PS C:\Users\Developer\Desktop\workspace\projects\the-mage-next-run> unity --help

Unity CLI v1.0.0-beta.13

Usage: unity [options] [command]

Commands:
  auth              Sign in, manage accounts, check login state
  build             Build a Unity project
  command           Execute commands on connected Unity Editor instances
  doctor            Print diagnostic information
  editor            Manage a Unity Editor installation
  mcp               MCP server and client configuration
  pipeline          Unity Editor Pipeline package
  projects          Manage Unity projects
  self-update       Update the Unity CLI
  setup             Set up coding agents to work with Unity
  skill             Read or install Unity CLI agent skills
  status            Show connected Unity Editor state
```

다음 명령어로 Unity 계정에 로그인한다.

```
PS C:\Users\Developer\Desktop\workspace\projects\the-mage-next-run> unity auth login

로그인 URL:
  [인증 URL 비공개]

로그인을 위해 브라우저를 열고 있습니다…

확인을 기다리는 중입니다…(취소하려면 Ctrl-C)

로그인되었습니다.
```

로그인 상태를 확인한다.

```

```

```
unity --version에 이전 버전이 계속 표시되면
```

## Pipeline 패키지 설치와 에디터 연결

Unity CLI가 실행 중인 Unity Editor와 통신하려면 프로젝트에 Unity Pipeline 패키지가 있어야 한다. 다음 명령어로 설치한다.

```
PS C:\Users\Developer\Desktop\workspace\projects\the-mage-next-run> unity pipeline install

🔍 Pipeline 패키지 설치를 시작하는 중...
📁 현재 디렉터리가 Unity 프로젝트입니다: the-mage-next-run
✅ Unity 프로젝트가 확인되었습니다(버전: 6000.6.3f1)
📦 프로젝트에 com.unity.pipeline 설치 중: the-mage-next-run
✅ com.unity.pipeline이(가) 이미 설치되어 있습니다

💡 최신 버전을 다시 설치하려면 --force을(를),
업그레이드하려면 "unity pipeline upgrade"을(를) 사용하세요
```

파이프라인을 설치했더라도 유니티 에디터가 실행 중이 아니면 연결되지 않을 수 있다. 유니티 에디터를 실행한 뒤에 다음 명령어를 실행하자.

```
PS C:\Users\Developer\Desktop\workspace\projects\the-mage-next-run> unity pipeline editors

프로젝트             PID  에디터 단계  엔드포인트  Pipeline
─────────────────────────────────────────────────────────────
the-mage-next-run         알 수 없음   없음       0.10.0-exp.1

Pipeline 패키지가 설치되어 있지만 서버에 연결할 수 없습니다.
Unity 에디터를 다시 시작해 보세요.
```

유니티 에디터를 다시 실행하고 파이프라인이 연결되면, 다음과 같이 사용할 수 있는 명령 그룹이 출력된다.

